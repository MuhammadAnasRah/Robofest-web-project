# Robofest Web Project 🤖

## About the Project
This repository contains website prototypes developed for the **Robofest competition**. Participants are required to build a website based on a specific theme or goal.

This edition focuses on the United Nations Sustainable Development Goals (**SDG 5: Gender Equality** and **SDG 10: Reduced Inequalities**).

## AI Tools Used
I used two AI agents to assist with generating different website implementations:
- **Claude** — Generated two versions of the website.
- **DeepSeek** — Generated five HTML website prototypes.

I reviewed the generated HTML files myself to explore the different approaches, compare implementations, and evaluate the generated code.
